
# ⚛ Physics Made Easy

A simple and interactive educational website designed for Class 9 students.

## About the Project

Physics Made Easy helps students understand physics through:

- Simple explanations
- Everyday-life examples
- Important formulas
- Worked numerical examples
- Interactive distance-time graph
- Multiple-choice quizzes
- Instant feedback

## Topics Available

1. Motion
2. Force and Laws of Motion
3. Gravitation
4. Work and Energy
5. Sound

## Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML Canvas

## How to Run the Project

1. Download all four project files.
2. Keep them inside the same folder.
3. Open `index.html` in a web browser.

No installation or additional software is required.

## Publish Using GitHub Pages

1. Create a new public GitHub repository named `physics-made-easy`.
2. Upload `index.html`, `style.css`, `script.js` and `README.md`.
3. Open the repository's Settings.
4. Select Pages from the sidebar.
5. Under Build and deployment, choose Deploy from a branch.
6. Select `main` and `/ (root)`.
7. Click Save.

Your website will be published at:

`https://YOUR-USERNAME.github.io/physics-made-easy/`

Replace `YOUR-USERNAME` with your GitHub username.
